# EDA 결과 정리 · 강남구/춘천시 사회적 고립 신호

- 분석 기간 2025년 7~12월, 대상 지역 서울 강남구·강원 춘천시
- 데이터 SK 통신 유동인구(250m 격자), 신한카드 결제, 통계청 SGIS 1km 격자 인구·가구
- "(판독)" 표시 값은 그래프에서 읽은 근사치
- 실행 명령 `python notebooks/run_eda_srh.py`, 수행 순서 SGIS 단독 EDA → 통신·SGIS 결합 → 카드 데이터2
- 표 저장 위치 `outputs/tables/srh_*.csv`, 그림 저장 위치 `outputs/fig_srh/`

## 분석 설정

| 항목 | 설정 |
| --- | --- |
| 공간 단위 | 통신 50m 원본을 250m 격자로 집계 (50m는 춘천 칸당 1명 미만) |
| SGIS 매칭 | 250m 셀을 1km SGIS 격자에 매칭, 비교는 1km 단위로만 수행 |
| 시간대 비중 | 셀별 시간대 유동인구 ÷ 셀 24시간 합계 |
| 야간 비중 | 22~04시 7시간 합계 ÷ 24시간 합계 |
| 주간 비중(day_share) | 10~16시 합계 ÷ 24시간 합계 (0~1 유계, 결측 없음) |
| 고령 비중 | 60대 이상 유동인구 ÷ 전체 유동인구 |
| 거주 셀 | 지역별 야간 비중 기준 AND 지역별 주택 수 기준 (4절 정의) |
| 격자군 | 6개월 평균 24차원 시간대 벡터 표준화 후 지역별 KMeans(k=8) |
| 이탈 지표 | 같은 지역·군집·월 내 day_share의 robust z (중앙값·MAD 기준) |

## 7. 후보는 고령 상위 25% 거주 셀 중 주간활동이 지속적으로 낮은 셀

### 지표 전환

- 1차 이탈 지표 `day_hold`는 야간 합계 0 또는 소수일 때 NaN/inf 발생, 결측률 23.1%
- 10~16시 합계 ÷ 24시간 합계인 `day_share`로 전환
- 90개 지역·군집·월 그룹에서 MAD=0 그룹은 전환 전후 모두 0개
- z=0 셀 비율 0.09% → 0.13%
- 새 지표에서 MAD=0 또는 유효하지 않은 셀 6개 후보 제외

### 후보 조건

- 거주 셀 내 고령 비중 상위 25%
- day_share robust z 음수인 달이 6개월 중 4개월 이상
- 고령 상위 25% 임계값은 전체 셀 기준 강남 0.2587·춘천 0.5362 → 거주 셀 기준 강남 0.2591·춘천 0.4165로 재계산

![고령비중과 robust z 후보](../outputs/fig_srh/05_srh_senior_percentile.png)

- 최종 후보 강남 65개, 춘천 192개
- `day_hold`·전체 셀 기준 1차 결과(강남 108·춘천 556)는 폐기
- 12월 단면에서 z>0 후보 존재 가능, 판정은 4개월 이상 지속 조건

### 인구집단 축이 고령 하나로 편중

- 주제 배경 키워드는 1인 가구 급증, 사회적 관계망 약화, 고독사, 은둔형 외톨이
- 은둔형 외톨이와 1인 가구 증가는 청년층 중심, 현재 분석은 60대 이상만 대상

| --- | --- | --- |
| 강남 | 청년 1인 가구 밀집 | 관계 단절 |
| 춘천 | 고령화된 중소도시 | 활동 위축 |

### 고립 유형 2종

| | 유형 1 · 활동 위축 | 유형 2 · 관계 부재 |
| --- | --- | --- |
| 양상 | 활동이 좁은 시간대 집중, 주말·평일 구분 없음 | 활동량 정상, 편의점·배달·무인점포 위주 소비 |
| 대상 | 고령층, 중소도시 | 청년 1인 가구, 대도시 |
| 데이터 | 통신 시간대별 인구비율 | 카드 업종 구성 |
| 개입 | 이동 수단, 가까운 거점 | 관계 형성 프로그램 |

- 개입 방식 상이, 유형 구분 없이는 자원 추천 불성립

### 고립 위험 셀을 어떻게 정의할 것인가에 대한 후보안 비교

| | 정의 | 즉시 분석 | 외부데이터 의존 | 주제 부합 | 핵심 한계 |
| --- | --- | --- | --- | --- | --- |
| A안 | 활동 단조로운 주거지역 | 가능 | 낮음 | 부분 | 단조로움과 고립의 연결 간접적 |
| B안 | 고령 많고 활동 적은 지역 | 불가 | 높음 | 부분 | 거주인구 정규화 필요, 결과가 고령 분포 지도에 수렴 |
