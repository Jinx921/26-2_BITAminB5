# 지도 데이터 규격 (채원·사랑용) · 2026-10-11

## 한눈에
- 지도는 엔진이 만든 **GeoJSON 파일**을 그대로 쓰면 된다. 위치: `engine/out/*.geojson`
- 좌표계는 **WGS84**(경도, 위도). 카카오·네이버·Leaflet 지도에 바로 올릴 수 있다.
- 칸 = 250m 정사각형 폴리곤 1개. `cell_id`로 현장기록·질문 결과와 연결한다.
- 파일은 엔진 도구를 실행할 때 다시 만들어진다. 기본값으로 만든 파일은 지금 레포에 들어 있다.

## 1. 레이어 목록

| 레이어 | 파일 | 칸 수 (강남 / 춘천) | 무엇을 그리나 | 볼 수 있는 사람 |
|---|---|---|---|---|
| 유형 지도 | `types_{지역}.geojson` | 526 / 1,615 | 전체 칸의 고립 유형 4가지 | 관리자만 |
| 후보 지도 | `candidates_{지역}.geojson` | 51 / 153 | 낮 활동이 줄어든 후보 칸 | 관리자만 |
| 배치 지도 | `sim_{지역}_k{거점수}_r{반경m}.geojson` | 긴급방문형 칸만 | 이동형 거점이 닿는 칸 / 안 닿는 칸 | 관리자만 |
| 시설 지도 | `facilities_{지역}.geojson` | 시설 333 / 870 (점) | 경로당·도서관·문화·공공체육(교류), 보건기관 | 시민·관리자 |

`{지역}` = `강남` 또는 `춘천`. 배치 지도는 기본값으로 `k3_r1000`, `k3_r3000` 두 개가 있다.

⚠️ **유형·후보·배치 지도는 시민 화면에 내보내지 않는다.** 동네를 위험도로 나누어 보여주지 않기로 했다 (낙인 방지, 에이전트 README 7절).

## 2. 파일 모양

```json
{
  "type": "FeatureCollection",
  "features": [
    {
      "type": "Feature",
      "geometry": {"type": "Polygon", "coordinates": [[[127.0133, 37.5212], ...]]},
      "properties": {"cell_id": "4011_7912", "emd_name": "남산면", "type": "관찰형", "gap_tag": "둘다", "priority": 4}
    }
  ]
}
```

## 3. 레이어별 properties

공통: `cell_id`(칸 ID, 문자열), `emd_name`(행정동 이름)

**유형 지도 `types_*`**

| 필드 | 값 | 화면에서 |
|---|---|---|
| `type` | `긴급방문형` / `연계형` / `예방인프라형` / `관찰형` | 색 구분 |
| `priority` | 1 / 2 / 3 / 4 (위 유형 순서와 같음) | 정렬·색 진하기 |
| `gap_tag` | `교류` / `보건` / `둘다` / `""`(공백 없음) | 아이콘·테두리 |

**후보 지도 `candidates_*`**

| 필드 | 값 | 화면에서 |
|---|---|---|
| `persistent_months` | 4 / 5 / 6 (6개월 중 활동이 줄어든 달 수) | 색 진하기 |
| `res_status` | `주거` / `용도미상` | 용도미상은 점선 등으로 구분 |

**배치 지도 `sim_*`**

| 필드 | 값 | 화면에서 |
|---|---|---|
| `type` | 항상 `긴급방문형` | |
| `covered` | 1 = 거점 반경 안 / 0 = 밖 | 닿는 칸·안 닿는 칸 색 구분 |

거점 위치 자체는 파일에 없다. `simulate_placement` 응답의 `result.chosen_sites`(`lat`, `lon`)를 점으로 찍는다.

## 4. 지킬 것
- `cell_id`는 조회·연결 키로만 쓰고 **화면에 글자로 보여주지 않는다.** 사람에게는 `emd_name`을 보여준다.
- 칸 ID 규칙: UTM-K(EPSG:5179) 좌표를 250으로 나눈 몫 `x_y`. 에이전트가 시민 위치의 지역을 판단할 때 이 규칙을 쓰므로 바꾸지 않는다.
- 유형 지도 파일에는 관찰형까지 **전체 칸**이 들어 있다. 질문 응답의 `display.map.points`에는 위축 칸(긴급방문형·연계형)만 들어 있다.

**시설 지도 `facilities_*`** (점, `cell_id` 대신 `fac_id`)

| 필드 | 값 | 화면에서 |
|---|---|---|
| `fac_id` | `GN_00000`, `CC_…` | 함께 가기·이동 도움 요청 키 (화면에 안 보임) |
| `name`, `addr` | 시설명, 주소 | 툴팁 |
| `kind` | `경로당` / `도서관` / `문화시설` / `체육시설(공공)` / `보건` | 아이콘 |
| `group` | `social`(교류) / `health`(보건) | 색 구분 |

만드는 법: `python prep/07_build_facility_map.py`. 엔진 거리 계산에 쓰는 시설만 넣었다 (민간 체육시설 제외).
경로당 이름: 강남구 원천의 ㉵(아파트 약자)를 "아파트"로 바꿨다 (10/17, 예: "은마㉵" → "은마아파트"). 그 외 이름·좌표·주소·fac_id는 원천 그대로.
⚠️ 강남 보건은 공공 보건기관 3곳뿐이다 (민간 의원 미포함).
